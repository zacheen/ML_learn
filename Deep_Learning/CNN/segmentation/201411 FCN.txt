	CNN 通常最後面會接 全連接層 才會有是什麼 class 的 Output
		但也因此限制了 input size (因為要接到固定數量的 FCL)
	但是 FCN 沒有 FCL 所以其實可以不固定大小
		限制 : 假設有 n 個 Maxpooling 層, 只要兩邊大小是 2^n 的倍數就可以輸入
		通常 UpSample 之後，會增加 channel 數量 (增加 Kernel 數量)
			當減少了空間解析度，為了不丟失太多資訊，用 channel 數量來補償

照理來說 應該輸入的大小應該不會影響某個區域的結果
	結論 : 沒有人反駁
	假設 做了2次 conv (padding same 3*3) 跟 一次pooling(2*2) 不考慮 channel(因為channel不會因為Input有變化)
	16 * 16 -> 8*8*channel -> 4 * 4
	8 * 8 -> 4*4*channel -> 8 * 8
	就中間獲得的特徵資訊 第一格看到的範圍 應該都是一樣的
		就是 ((1+2)*2+2)
