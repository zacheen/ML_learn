< Probability >
    Distribution 其實就是看 每個結果的 Probability
P(x,y) : x,y 同時發生的機率          (Joint Probability)
    Probability of x and y
P(x|y) : 當 y 已經發生, x 發生的機率 (Conditional Probability)
    Probability of x given that y
    P(y) : Prior Distribution
P(x,y) 與 P(x|y) 關係 (Produce Rule)
    P(x|y) * P(y) = P(x,y)
P(x,y | z) : 當 z 已經發生, x,y 同時發生的機率
P(x;y) : 我已經確定 y (固定 或 100%會發生), x 發生的機率


Sum Rule, Marginalization : 
    P(x) = sum(P(x,y) for all y)
    P(x|z) = sum(P(x,y|z) for all y)
        規則 : 把某個變數的可能性加起來，就可以去掉那個變數

    Sum Rule : emphasise - we what to cal P(x) by adding all possible y
    Marginalization : emphasise - we don't care about y, so we try to remove y
        這個 y 叫做 Nuisance Variable : 多餘變數、干擾變數

Bayes' Rule
    P(Hypothesis|Evidence) or P(H|E) : the posibility of Hypothesis given Evidence
        = P(E|H) * P(H) / P(E) 
        = P(E,H) / P(E)
            P(H) : Prior Distribution   (先驗 : 因為是還沒有任何線索 得出的機率)
            P(H|E) : Posterior Distribution (後驗 : 因為是有了新線索 得出的機率)
            P(E|H) : Likelihood
            P(E) : Evidence
        反正就記得 條件 不可能在同一邊 : P(A|?) 不可能再乘P(A) 所以P(A)一定在下面
    推導出新公式
        P(A,B) = P(A|B) * P(B) = P(B|A) * P(A)
    Chain Rule (expand from Bayes' Rule)
        P(x,y|z) = P(x|y,z) * P(y|z)

< likelihood >
L(y|x) = P(x|y)

likelihood function
    L(θ) = L(θ|X) = L(θ;X) 
        = P(x1,x2,x2...,xn | θ) = P(X|θ)
        = P(x1|θ) * P(x2|θ) * ... * P(xn|θ)
        = MUL_n( p(xi | θ) )
            θ 包含了所有的權重（weights）與偏差（bias）
log-likelihood function
    log L(θ) = ℓ(θ) 
        = log MUL_n( p(xi | θ) )
        = sum_n( log p(xi | θ) )

< odds >
odds = p / (1-p)
    會發生的機率 與 不發生的機率 的 比例

log odds
    假設某事件x發生的機率是 p, p 只能在 0 到 1 之間
    當我對 odd 取 log 時
        log( p(x) / (1-p(x)) )
            p(x) > 0.5 時 log odds 為正
            p(x) < 0.5 時 log odds 為負
    因此可以 把這個比例轉成一個線性、可加、無界的尺度

< Expectation >
    Discrete distribution
        E[X] = sum( p(xi)*f(xi) for all i )
            f(xi) 可以是一個 function, 或本身 xi 數值 (f(xi) = xi)
    continuous
        E[X] = ∫ x*f(x) dx
            f(x) is PDF

joint probability table
    Tij = P(ij)

discriminative model VS generative model
    Y is output(labels), X is input(feature)
    discriminative model :
        learning P(Y|X)
            since model is learning the relationship between X and Y "directly"
    generative model  
        learning P(X,Y)
            usually learning P(X|Y) and P(Y), since P(X,Y) = P(X|Y)*P(Y)
                P(Y) is Prior Distribution, represent the distribution of Y
                P(X|Y) is Likelihood, represent if knowing the output is Y what should X looks like

-- < 機率分布 Probability Distribution > ----------------------------------------------------------
Probability Distribution
    Distribution 是描述某個 random variable 各個可能值出現機率的分布
    Probability Distribution 的特點是 總合為1

Discrete distribution
    Probability Mass Function (PMF)
    對 PMF 相加 可以得出 CDF
        
continuous distribution
    因為是 continuous 所以 我沒辦法說特定一個點 的機率是多少
    但可以說某個數字以下(或某個區間)的機率是多少
    Probability Density Function (PDF)
        Gaussian distribution（高斯分佈）與 Normal distribution（常態分佈/正態分佈) 是相同的
    對 PDF 做積分 可以得出 CDF

Cumulative Distribution Function (CDF) 累積分佈函數

特殊的 distribution 名稱
Bernoulli distribution
    在 1 次獨立試驗中，這一次只會出現 0/1 兩種結果
        P(Y = 1) = p
        P(Y = 0) = 1 − p
    如果我想要用一個式子表示 P(Y)
        P(Y) = p^y * (1-p)^(1-y)
            P(Y = 1) = p     = p^y*(1-p)^(1-y), y=1 = p^1*(1-p)^(0) = p
            P(Y = 0) = 1 − p = p^y*(1-p)^(1-y), y=0 = p^0*(1-p)^(1) = 1-p
Binomial distribution : 
    在 n 次獨立試驗中，每一次只會出現 0/1 兩種結果
    橫軸表示 再n次的試驗中總共成功x次 
    縱軸表示 成功x次 的機率
    (Binomial(n, p) 就是 n 次獨立的 Bernoulli 加起來)

normal distribution (Gaussian distribution) : 常態分布
    符號 : 𝒩(μ, σ²)
        μ 是平均數 mean, 也就是鐘形的中心位置
    Gaussian function (Gaussian Equation) 指的是一個函數形狀
        f(x) = e^(-(x-μ)² / (2σ²))
    Gaussian distribution function <Gaussian distribution function.png>
        加入 normalization term : (1/(2πσ^2)^(1/2))
    p(x) = (1/(2πσ^2)^(1/2))*Gaussian function
         = (1/(2πσ^2)^(1/2))*e^(-(x-μ)² / (2σ²))
         另外一種形式 (把 σ 跟 1/2 提取到外面)
         = (1/σ(2π)^(1/2)) * e^(1/2)*(-(x-μ)² / σ² )
            x-μ 可以替換成 error
    
zero mean normal distribution
    符號 : 𝒩(0, σ²)
    代表 分布的中心在 0

Naive Bayes
    Why Naive 
        In Bayes, all features are assumed to be independent of one another.
        However, even this condition is usually incorrect in real life
        the result still turns out to be good.
    步驟 
        以 binary spam 當作範例
            通常會使用 "Odds"，而不是普通機率，處理二元分類（Binary Classification）問題
            因為這樣 P(E) 在計算過程中會被消除
            普通機率 : 
                P(H_pos|E) = P(E|H_pos) * P(H_pos) / P(E)
                P(H_neg|E) = P(E|H_neg) * P(H_neg) / P(E)
                    所需機率 : P(E|H_pos), P(H_pos), P(E|H_neg), P(H_neg), P(E)
            但是如果是 Odds 的話
            Odds :
                P(H_pos|E)/P(H_neg|E) = P(E|H_pos) * P(H_pos) / P(E|H_neg) * P(H_neg)
                P(H_neg|E)/P(H_pos|E) = P(E|H_neg) * P(H_neg) / P(E|H_pos) * P(H_pos)
                    所需機率 : P(E|H_pos), P(H_pos), P(E|H_neg), P(H_neg)
                        可以不需要 P(E)
                        且通常 P(E) 很難求
        計算 prior + easier to cal
            在沒有看到任何字之前，是 spam 的機率
            ori      : prior = P(spam)/P(normal)
            logprior : log( amount of spam / amount of normal )
        計算 likelihood + Laplace smoothing + easier to cal
            Laplace smoothing : 避免某個字沒出現導致機率為 0
            easier to cal : log
            ori :   loglikelihood[word] =        P(word_i in spam | spam) /   P(word_i in normal | normal) 
            adjust: loglikelihood[word] = log( L_P(word_i in spam | spam) / L_P(word_i in normal | normal) )
                L_P(word_i in spam | spam) = word_i 在 spam 句子中出現幾次"+1" / spam 總共有幾個單字 "+V"
                    Laplace smoothing : +1 / +V
                    Multinomial Naive Bayes : 會重複計算重複的單字
                    Bernoulli Naive Bayes   : 一個句子中重複出現的單字只算一次
                V : 所有不重複單字的總數
                word_i in spam : word_i 在 spam 裡面出現過多少次
        預測新文件
            pred = logprior + sum(loglikelihood[word] for word in "free win money")
            threshold = 0 # 如果希望更嚴格可以往上調整
            if pred > threshold :
                is spam
